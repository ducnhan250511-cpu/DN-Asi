# Kiểm tra trước khi Deploy

- [ ] Giải nén ZIP, không tải nguyên ZIP làm repository.
- [ ] `package.json` và `src/` nằm ở thư mục gốc.
- [ ] Không commit `.env`, token, mật khẩu hay thông tin database.
- [ ] Framework preset: TanStack Start.
- [ ] Vercel dùng `npm install --no-audit --no-fund`.
- [ ] Build command là `npm run build`.
- [ ] Mở Build Logs nếu deploy lỗi.
- [ ] Sau deploy, thử gửi câu hỏi ngắn trên Chrome Android.
- [ ] Kiểm tra website ở cả chế độ dọc và ngang.
